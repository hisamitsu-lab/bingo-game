# iPad用オフライン・ビンゴ抽選機

1〜75を重複なく抽選します。抽選履歴はこのiPad内に自動保存されます。HDMI接続中は、iPadとスクリーンに同じ大きな画面が表示されます。

## 初回だけの導入（おすすめ）

Safariでこのフォルダを**HTTPSのWebアドレス**として開いてください。`index.html`をFilesアプリから直接開く方法では、iPadOSの仕様によりオフライン化できません。

1. このフォルダを、使用するiPadから開けるHTTPSの静的Webサイトにそのまま配置します（社内Webサーバー、制作会社の一時公開先など）。
2. iPadのSafariで `https://（配布先）/index.html` を開きます。最初の画面が完全に表示されるまで待ちます。
3. Safariの共有ボタン（四角から上矢印）を押し、**「ホーム画面に追加」** → **「追加」** を選びます。
4. Safariを閉じ、ホーム画面にできた「ビンゴ」アイコンから一度起動します。
5. Wi‑Fiをオフにして起動・抽選できることを確認します。以後、ネット接続は不要です。

> 初回の配布だけにネットワークを使います。ホーム画面へ追加後は、アプリ本体・抽選履歴ともiPad内で動作します。

## 当日の使い方

1. HDMI変換アダプタまたはUSB-C HDMIケーブルでiPadとスクリーンを接続します。
2. ホーム画面の「ビンゴ」を開きます。横向きにするとスクリーンで特に見やすくなります。
3. オレンジの **「スタート！」** を1回押すと、未抽選の数字から1つを選びます。同じ数字は二度出ません。
4. 下部の丸い数字が抽選履歴です。途中で閉じても、同じiPadなら履歴は残ります。
5. 最初から始めるときは **「リセット」** → **「リセットする」** を選びます。確認後、履歴は消去されます。

## 大事な確認

- 本番前に、ホーム画面のアプリを開いた状態でWi‑Fiをオフにし、数字を1つ引けるか試してください。
- 外部スクリーンはiPad画面のミラーリングです。スクリーンにだけ別内容を出す仕様ではありません。
- アプリを削除したり、SafariのWebサイトデータを消去したりすると、抽選履歴も消えます。

## フォルダの内容

- `index.html` — アプリ画面
- `styles.css` — iPad・大型スクリーン向けレイアウト
- `app.js` — 重複なし抽選・履歴保存・リセット確認
- `service-worker.js` と `manifest.webmanifest` — ホーム画面追加後のオフライン動作
